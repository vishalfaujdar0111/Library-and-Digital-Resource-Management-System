# Library-and-Digital-Resource-Management-System
<br>
📚 A web-based Library and Digital Resource Management System.
<br> 
<br>
💻 Built with HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.
<br>
<br>
➡️ Features include book search, issue/return, auto fine calculation, e-book access, and email notifications with role-based dashboards for Admin, Librarian, and Student.
<br>
<br>
🏫 This is a Mini Project developed by a group of 4 students as part of B.Tech CSE 3rd Year curriculum at GLA University.
